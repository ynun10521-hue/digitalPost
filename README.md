# 손편지 우체국 — HTML/CSS/JS만 사용한 버전 (DB 없음)

서버나 DB 없이 브라우저에서만 동작하는 버전입니다. `index.html`을 더블클릭해서 바로 열어보시면 됩니다.

## 폴더 구조
```
postcard-html-project/
├── index.html          # 라디오탭 UI (엽서 만들기 / 모아보기)
├── css/style.css        # 이전 Tomcat 버전과 동일한 파스텔 디자인
├── js/storage.js        # DB 대신 쓰는 저장소 (아래 설명 참고)
├── js/main.js           # 미리보기 바인딩 + html2canvas + 저장/목록/상세
└── images/stamps/*.svg  # 우표 5종
```

## "DB 없이" 데이터는 어떻게 저장되나요? (`js/storage.js`)
Servlet + SQLite 대신, 브라우저 안에서만 데이터를 들고 있도록 만들었습니다.

- **Claude.ai 안에서 미리보기로 열었을 때**: 대화창에 내장된 `window.storage`(키-값 저장소)를 사용해서, 대화를 벗어났다 돌아와도 엽서 목록이 유지됩니다.
- **다운로드해서 내 컴퓨터에서 `index.html`을 직접 열었을 때**: `window.storage`가 없으므로 자동으로 브라우저의 `localStorage`로 전환됩니다. 같은 브라우저로 다시 열어도 목록이 남아있습니다. (단, 브라우저 캐시/방문기록 삭제 시 함께 지워집니다.)
- 둘 다 쓸 수 없는 예외적인 경우엔 메모리에만 저장되어 새로고침하면 초기화됩니다.

즉, 코드를 수정하지 않아도 **어디서 여느냐에 따라 알아서 적절한 저장 방식**을 씁니다.

## Tomcat/SQLite 버전과 다른 점
| | Tomcat+SQLite 버전 | 이 버전 (HTML/CSS/JS) |
|---|---|---|
| 서버 | 필요 (Tomcat) | 불필요 |
| 데이터 저장 | SQLite `postcards` 테이블 | 브라우저 저장소 (`window.storage` 또는 `localStorage`) |
| 여러 사람과 데이터 공유 | 가능 (같은 DB를 봄) | 불가능 (각자 브라우저에만 저장됨) |
| 배포 방법 | `.war`를 Tomcat에 올림 | 폴더를 그대로 웹 호스팅에 올리거나 로컬에서 파일로 열기 |

## 실행 방법
1. 압축을 풀고 `index.html`을 브라우저로 엽니다 (더블클릭해도 됩니다).
2. 우표/배경을 고르고 글을 쓰면 오른쪽 미리보기에 바로 반영됩니다.
3. **이미지로 저장**: PNG 파일로 다운로드됩니다.
4. **저장하기**: 브라우저 저장소에 기록되고, `모아보기` 탭에서 목록으로 확인할 수 있습니다.

정적 파일이라 GitHub Pages, Netlify 같은 무료 호스팅에 폴더째 올리기만 해도 바로 서비스할 수 있습니다.
